# 悬停提示审计与整改

审计日期：2026-11-05。范围为应用 `src/` 的现有提示，包括原生 `title`、全局提示层、富内容提示、时间轴自定义预览，以及画布库生成的控件提示。按源码触发站点计数，循环实例不重复计数；翻译键、窗口标题、数据字段 `title` 不单独算提示。Markdown/导入内容自带的链接标题属于用户内容，不批量删除。

## 判定及整改方案

| 类型 | 判定 | 整改 |
| --- | --- | --- |
| 与可见文字重复 | 滥用；用户已经能读到 | 删除提示 |
| 常见外观且上下文明确 | X 关闭、折叠箭头、尺寸手柄、正文复制/编辑、输入发送等通常无需再次解释 | 删除提示，保留独立 `aria-label`、焦点与原动作 |
| 只有图标时才需要名称 | 宽屏标签已经解释；窄屏隐藏文字后需要提示 | `data-tooltip-icon-only`，只在无可见文字时显示 |
| 名称或路径完整可见 | 重复显示没有信息增量 | `data-tooltip-overflow`，只在实际裁切时显示；主动缩写的路径仍保留完整内容提示 |
| 非通用业务图标、操作范围、状态和数据 | 外观不能表达引用/继承/上下文、定位范围、缺失原因或 Token 构成 | 保留，长操作说明压缩成一句 |
| 授权范围、执行后果、必要帮助 | 不应要求先悬停才能做决定 | 移到对应控件旁或面板正文 |
| 整块阅读内容覆盖提示 | 打断阅读；既不精确也不利于发现操作 | 移除大面积触发，必要操作提供明确的小入口 |

不改节点、连线、排版、发送和草稿的行为。删除提示不删除无障碍名称。保留的提示继续支持键盘聚焦和 Esc 收起，不拦截拖动。

## 共用实现

全局提示层按两个可选标记检查是否值得显示；两标记同时存在时满足任一条件即可。无信息增量时同时抑制自定义提示和浏览器原生提示。检查裁切包含目标及其子元素，覆盖文字省略、单行截断与多行裁切；主动改写/缩写内容由调用方保持普通提示。针对画布库自带的放大/缩小标题，仅抑制其提示，不替换该库的交互实现。
