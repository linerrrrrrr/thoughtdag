# 编辑与退出交互标准

> **先分类，再定义退出。短名称外点保存；长内容外点收起并保留草稿。发送、生成、授权、删除和配置提交必须明确触发。Esc 只退出最上层，绝不提交。**

已回答节点及其右侧详情不放置续问输入框、发送工具条或模型与目录配置。继续提问通过从节点拉出连接创建空白子节点，在新节点明确输入并发送；选文探索同样创建带引用上下文的空白子节点，不立即生成。Agent 来源的子节点保留对应运行时与工作目录，实际发送根据来源、目录、附件、引用与上下文变动决定是否接续原生会话。

执行中的 Agent 可通过标题栏明确停止，或在“更多”中打开临时文字指令编辑器。外点收起并保留草稿，Esc 丢弃当前指令草稿；只有明确发送才提交。补充仅在运行时确认接收后记录到本轮问题和活动；失败保留草稿，迟到回执不得清空发送期间的新输入。任务结束后不保留指令编辑器。工作目录与权限在所属配置入口明确提交，不能通过关闭阅读详情或点击外部触发。

文件链接右键属于临时菜单：外点仅关闭，Esc 返回链接；支持方向键、Enter 和键盘菜单键。文件预览为只读模态，Esc 只关闭当前预览并归焦；打开、定位和复制必须明确触发。源码与脚本不会通过文件链接执行。节点、阅读侧栏、活动过程中的文件链接使用相同路径解析与操作。

本规范适用于画布、侧栏、阅读器、菜单和对话框。右键菜单中的节点重命名属于**单字段页内编辑（inline editing）**；卡片上的名称与摘要属于**多字段页内编辑**，均不是模态对话框。节点卡片的大小、滚动和选中状态也不是编辑状态。

空名称规则必须按对象说明：节点空名称恢复自动名称；空项目名保留原名；框标题可为空并显示命名提示。不能用空字符串判断“无草稿”：**清空内容也是草稿**。

**对话节点卡片分为三个区域。** 顶部状态与操作栏的空白处可按住拖拽，按钮独立响应操作；第二块为名称与摘要，完整视图默认只显示收起的编辑入口，单击展开；第三块展示原始问题、回答及其操作。简略视图直接显示名称与摘要，单击可编辑，隐藏问答正文；极简视图仍保留名称用于导航。标题按可用宽度显示，不在简略视图按固定字符数截断。

顶部总量、占比条及工具调用标识均保留拖拽能力，不作为按钮或禁止拖拽区域。总量常显，工具仅显示图标与次数。总量、工具图标与次数及占比条作为同一个悬停与键盘聚焦单元，共用一张显示各部分数量、占比和工具名称的明细卡；组内移动不切换提示。开始拖拽即收起提示，不拦截指针事件。总量与占比统一统计本轮问题、回答、工具记录及已记录思考，标明文本估算，不代表 API 计费用量；缺失思考记录不显示为实测零。名称与摘要使用贯穿卡片宽度的独立分区，通过分隔线与上下区域区分，编辑器不再另套内部卡片。

名称与摘要作为一组多字段草稿：外点、Tab 离开整个区域或点击收起均保留会话草稿（包括空值）；保存或 Ctrl/Cmd+Enter 才一次提交两个字段，并形成一个撤销步骤；Esc / 取消丢弃草稿，保留正式内容。摘要 Enter 换行，中文组合输入期间 Enter/Esc 不触发操作。编辑时临时使用自然高度，关闭恢复原卡片尺寸。AI 自动填充只在点击按钮后调用，结果仅写入草稿；关闭或切换回答时取消请求，迟到的结果不能覆盖新编辑。生成失败保留草稿并允许重试。保存的名称与摘要仅用于展示，不替换问题、回答或上下文内容，也不被后台自动摘要覆盖；保存空摘要时不回退显示自动摘要。

卡片与右侧详情采用一致的对话排版：问题靠右显示为轻底色气泡，回答使用连续正文，复制、修订、重新生成和版本操作位于回答下方。名称与摘要入口保持轻量，展开时用同一编辑区域容纳两个字段和 AI / 保存 / 取消操作；卡片与右侧详情共用草稿，切换编辑位置不提交、不丢失内容。简略卡片的名称和摘要保留缩放字号补偿，完整问答不重复显示摘要正文。

右侧详情保留固定标题栏，阅读区域占用其余高度并独立滚动；名称与摘要编辑也属于该滚动区域，窄栏或较低窗口仍可滚动访问保存按钮。已回答节点没有底部续问区域。角色、附件和上下文检查项保留在问答后；归档等次要操作通过标题栏“更多”进入。代码块在自身区域横向滚动，不能撑宽正文或遮挡操作。

**节点输入与缩放。** 新节点首问输入框的显示由节点详细程度和编辑会话决定，单选、多选、打开详情均不单独控制画布输入框。在自动详细程度下，闲置节点缩至 80% 进入概览，重新放大至 90% 回到完整卡片；中间缓冲区沿用当前层级，避免临界点抖动。概览和极简视图收起闲置首问输入；已有草稿不等于正在编辑，也不强制展开。已回答节点在所有详细程度下均不显示续问输入。手动详细程度仍按节点锁定优先于全局设置执行。

正在编辑名称、问题、回答或使用首问完整输入区域时，卡片临时保持完整视图；缩放不重建输入框、不移动焦点、不清空草稿。输入及其按钮、引用候选属于同一边界；缩放控件和节点尺寸手柄不结束编辑。外点或 Tab 离开首问区域仅结束编辑保护并保留草稿，再按当前详细程度显示；Esc 先关闭引用等内层，再让生成输入失焦并保留草稿，绝不发送。正文修订的 Esc 仍按原规则取消修改。新建提问明确进入首问编辑；已有空节点不会因放大或重新进入视口自动抢焦点。运行中的工作流及等待明确授权的节点保留原有工作状态展示。

**选中与阅读分离。** 单击节点仅选择画布对象并显示对象格式；对象格式卡片面向节点几何格式，不提供“查看详情”入口。双击节点顶部状态栏的非按钮区域可打开或切换右侧详情；再次双击当前阅读节点顶部则收起详情并保留会话草稿；简略视图使用相同顶部区域，极简视图可双击名称区域。节点上的“查看详情”书本按钮采用相同切换规则：当前节点详情已打开时点击收起，否则打开或切换至该节点；按钮操作不改变画布选区，收起保留会话草稿。右键菜单中的“查看详情”继续提供明确打开入口。详情固定当前阅读节点，单击其他节点、框选多个对象或清空选区均不切换或关闭详情；详情内的上下文导航可明确切换阅读对象。格式卡片与详情可同时使用，各自标明对应节点。关闭详情或按 Esc 退出详情不清空选区；内层编辑或菜单优先消费 Esc。正文、名称编辑区和顶部按钮的双击保留各自行为，不冒泡触发详情。宽度调节手柄不显示悬停、点击说明卡片；拖动调宽和双击恢复默认宽度保留。窗口宽度不足 960px 时自动收起详情并释放工具栏空间，保留选区与会话草稿；恢复宽度后不自动重开，需再次明确打开。删除正在阅读的节点或切换画布时关闭详情。

对齐与分布点击后直接执行，不再弹出确认窗口；操作仍可撤销。画布顶部工具栏可切换框选对象：默认只选节点，不自动选择连线；线条模式选择与选框相交的可见连线。松开鼠标后保留框选范围及两种对象的命中结果，切换类型仍使用这次范围；某种类型没有命中时也保留范围，允许切回。缩放和平移不改变范围，外点或退出选区时清除；移动或调整节点几何后结束原范围。没有保留范围时，切到线条接续选择已选节点之间的连线，切回节点选择所选线条的端点。Ctrl/Cmd/Shift 支持追加选择，Ctrl/Cmd+A 按当前对象类型全选。

**多选用于批量操作，分区定义空间范围。** 单击、追加选择、框选和键盘导航均独立选择节点；尺寸、位置、对齐和自动排版按实际选区执行。对象格式面板并列提供「对齐」菜单和「创建分区」按钮；创建分区明确点击后执行，选区包含分区框时禁用。这些操作均可撤销，不改变上下文连线。

分区框用于为空间范围命名和导航，成员由操作开始时完整落在框内的节点决定；移入移出即改变范围。选择框不会隐式选中内容，「选择分区内容」和「选择框及内容」明确指定操作范围。开启联动后移动框带动当前内容，框外节点保持原位；关闭联动仅移动框。缩放框不改变内容尺寸或位置；删除框保留内容与连线。按选区创建分区只根据实际所选节点定边界。

「更多」菜单通过「排版设计」打开非模态工作面板；面板以并列单选项展示应用范围、节点布局、布局方向、间距密度和连线默认路径，不提供「一键排版」按钮或下拉选择器。有选区时默认作用于选中内容，无选区时默认作用于整张画布并禁用「选中内容」；保持手动位置时禁用间距密度。选择选项只修改会话草稿，预览不提交，明确点击「应用排版」才提交配置与排版。排版按连接关系和稳定创建顺序恢复主链与分支，不以拖动后的坐标决定先后；选中的对话和材料节点均可参与，未选节点保持原位。选中分区时纳入当前框内内容，整理后适配分区边界，嵌套分区由内到外处理。整个操作形成一个撤销步骤；点击排版入口或面板不清空选区，预览的坐标、尺寸和测量值不得写回正式状态。

排版计算在后台进行，忙碌时阻止重复提交；关闭、取消、改变选区或配置后，旧预览不得重新出现。计算期间拖动、撤销、改变尺寸或连接、切换画布均使旧结果失效，不能覆盖新操作。分区成员只在计算前确定一次，不能根据排版后的覆盖关系吸收新成员。若分区归属与主链顺序无法同时满足，保留原图并提示调整分区或仅选节点排版。

分区在应用排版和「适配内容边界」时按内容的完整尺寸自动收紧宽高，统一保留顶部标题空间和四周内边距；标题根据现有框宽和顶部空隙缩放，不以长标题或概览缩放撑大框体。嵌套分区使用操作开始时的成员快照，从内到外适配，一次完成且可一步撤销；空分区保留手动尺寸，比例锁定的框在包含内容的前提下保持比例。

多选节点后，整个选区色块（包括节点之间的空隙）都可按住拖动，所选对象按相同位移移动，已链接分区按现有规则携带内容并去重。选区内仍可右键打开节点菜单，中键/右键拖动和滚轮继续操作画布。点击选区外退出多选，目标点击仍生效；对象格式、对齐菜单和对象类型切换属于选区编辑边界，Ctrl/Cmd/Shift 追加选择也保留原选区。阅读面板保持打开但不阻挡取消选区；模态确认期间保留后台选区。无内层编辑时，Esc 退出多选。

单节点与多选外框共用横向、纵向和双向尺寸手柄，只调整节点尺寸，位置不变；右下角双向拖动按两个方向调整，锁定比例的节点按相对变化较大的方向等比调整。多选时只保留外框一套手柄。移动或缩放结束各形成一个撤销步骤，拖动中 Esc 或指针取消恢复起点并保留选区及内容草稿。移动区和尺寸手柄支持方向键每次调整 1 个画布单位，Shift 加大至 10 个单位，也可在节点编辑面板输入精确尺寸。连线期间收起尺寸手柄，调尺寸期间弱化并禁用对应连接目标；短材料卡的宽度手柄避开侧端口，空间不足时使用角部或面板调整。线条批量编辑属于非模态多字段工作面板：只应用改动字段，明确点击应用后整体提交；关闭保留会话草稿，Esc 先取消草稿，再退出面板。删除须明确确认。

**节点高度与比例。** 对话和材料节点区分自动高度与固定高度；对象格式在高度字段旁标明「自动」「固定」或「混合」，自动时数值表示当前测量高度。未锁定比例时，仅调整宽度保留自动高度并重新换行；明确输入高度或纵向拖动后使用固定高度，超出内容在节点内滚动。锁定比例时调整任一尺寸按原比例联动另一维。「恢复自动高度」必须明确点击，清除固定高度与概览高度保持状态，同时解除比例锁定；存在锁定时提前显示说明。恢复保持节点宽度、位置和内容，只丢弃高度字段草稿，其他尺寸或位置草稿保留且不隐式提交；单个或多个内容节点的恢复形成一个撤销步骤。分区框使用固定尺寸，不提供此入口；混合选区按对象格式的节点/分区范围分别处理。尺寸草稿未提交时切换比例锁定，先按原锁定状态应用字段，再变更锁定状态，整次动作只形成一个撤销步骤。

`@` 引用候选保留补全习惯：普通 Tab 接受当前建议；Shift+Tab 离开且不选择；无候选时 Tab 直接离开；Esc 只收起候选，不清除正文。

工具栏下方的卡片共用单一显示位置，统一为 320px 宽，窄屏受可用宽度约束。打开另一工具卡片时收起当前卡片，不层叠显示；对象格式、连线编辑与排版工作面板在临时卡片关闭后恢复。切换仅收起并保留草稿，不提交配置或执行生成；右侧节点详情在宽度足够时仍独立保留。模型连接与选择入口位于左上项目工具栏。

对象格式卡片初次出现及切换选区时默认收起，只显示标题与选区摘要；点击收起卡片的任意位置（含标题、摘要与留白）即可展开，展开后点击顶部摘要区域可收起。展开入口支持键盘 Enter / Space，中文组合输入期间不触发；格式控件独立操作，同一选区内的编辑不自动收起卡片。

顶部两组工具栏按实际可用宽度保持单行：依次省略名称和按钮文字、将次要入口收进“更多”；最窄时框选对象使用原生选择器，保留当前模式和选区切换语义。搜索独立展开在工具栏下方，不改变顶部行高。收纳只改变入口，不卸载已打开的工具工作面板或清除草稿；右侧详情仍遵守宽度不足自动收起规则；Esc 返回入口，入口已收纳时返回“更多”。等待处理的状态收纳后，“更多”仍显示提示标记。

## 不可破坏的边界

1. **编辑器是完整区域。** 输入框、保存/取消、内部按钮、滚动条和弹出选择器均属于交互边界。字段间 Tab、滚动和尺寸拖拽不应提前结算编辑。
2. **一个事件只结算一次。** 外点按由内向外的顺序关闭目标之外的层，遇到包含目标或禁止外点关闭的层停止；不吞掉目标的点击，不抢新目标焦点。Esc 只处理最上层，不穿透到父窗口或画布取消选区。
3. **副作用只能显式执行。** blur、外点、取消、Esc 不得触发生成、授权、删除、上传或密钥保存。便笺用于待填材料时，明确保存才可推进原有流程。
4. **键盘与中文输入同等重要。** 所有 Enter/Esc 处理先检查 `isComposing` / `keyCode === 229`。多行正文 Enter、Shift+Enter 换行；内容提交可用 Ctrl/Cmd+Enter。聊天输入保留已声明的 Enter 发送、Shift+Enter 换行。
5. **草稿与正式值分离。** 输入时写入 `ui-store.drafts`，外点只隐藏编辑器，重开或画布/侧栏切换恢复同一草稿；取消或保存成功才清除。缓存仅在当前应用会话内有效，刷新不保证恢复。异步保存失败保留输入，不能误清保存期间新输入。密钥等敏感值只保留在当前表单内存，不写通用草稿或持久存储。
6. **焦点跟随任务。** 模态进入后定位焦点、Tab 不越界、键盘退出归还焦点；危险确认默认聚焦取消。非模态面板不锁住画布。关闭按钮始终保留，不能让鼠标外点成为唯一出口。

## 实现入口

- `src/lib/use-dismissable-layer.ts`：统一的外点 / Esc 栈、模态焦点约束；同一个交互边界可包含多个 DOM ref（含 portal）。临时菜单启用 `dismissOnFocusOutside`；用 `dismissOnOutside: false` 标识常驻或受保护窗口。画布选区可用 `independentOutside` 独立检查外点，不受无关常驻面板阻挡；仍遵守模态保护及 Esc 层级。触发器在编辑时会卸载的场景提供 `restoreFocusRef`，让键盘退出回到重建的触发器。
- `src/lib/use-inline-edit-dismiss.ts`：完整编辑区域的外点和焦点离开，只执行一次。调用方明确提供 `onOutside`（本地保存或保留草稿）与 `onCancel`（取消）；不在通用 hook 中猜测业务提交方式。
- `src/lib/ui-store.ts` 的 `setDraft(key, text, true)`：保留空草稿。键按对象和字段构造；提交成功/取消用 `setDraft(key, '')` 清除。
- 不再为普通浮层重复注册 document/window 的 Escape 或外点监听；不得使用全局 Enter 模拟确认。触发器应有可访问名称，菜单状态用 `aria-expanded`，模态使用 dialog / alertdialog 语义。

覆盖入口：`ThoughtNode`、`ProjectSwitcher`、`FrameNode`、`ContentNode`；`focus-panel` 中 Question/Response/Role/Related/Highlights；SelectionToolbar；MaterialReader；MemoryPage、TopicsPanel、RoleManagerModal；ModelPicker、AgentCwdChip、AgentPermissionChip、RecallChip、NodeMention、HeaderActions、NodeContextMenu、SelectionArrangeMenu；SearchBar、CanvasChat、DiagnosticsPanel；各导入、设置、总览、确认与分享窗口。`ParadigmNode` 常驻表单、Notebook 只读内容、普通折叠详情不创建虚假的编辑会话。

## 必须验收

- 空白画布、同卡空白、另一张卡片：能退出正确层，目标点击仍生效。
- 保存/取消按钮、内部 Tab、菜单 portal、滚动、缩放与拖拽：不误退出或重复保存。
- Enter、Shift+Enter、Ctrl/Cmd+Enter、Esc、中文候选确认：行为一致，无隐式网络调用。
- 草稿修改、全部清空、父容器关闭、重新打开、画布/面板互换：内容可恢复；取消后恢复正式值。
- 嵌套层只消费一次 Esc；危险确认焦点在取消时按 Enter 仍取消；关闭后焦点可继续操作。
- 已提交短字段和正文可按现有撤销机制回退；单次操作不产生重复历史记录。

## 设计依据

[Ant Design · 直截了当 / 页内编辑](https://ant.design/docs/spec/direct-cn/)给出单字段原位编辑、确认/取消和焦点定位；[Typography editable](https://ant.design/components/typography-cn/#editable)区分 Enter 完成与 Esc 取消；[数据录入](https://ant.design/docs/spec/data-entry-cn/)区分短文本与长文本输入。

[Modal](https://ant.design/components/modal-cn/)、[Drawer](https://ant.design/components/drawer-cn/)的外点/键盘行为可配置，普通模态与确认模态默认策略也不同。[WAI-ARIA 模态对话框](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)要求模态焦点管理和 Esc 关闭；[菜单模式](https://www.w3.org/WAI/ARIA/apg/patterns/menubar/)说明当前菜单退出与焦点归还。

**官方手册未规定所有输入失焦保存。上面的草稿、风险分级和副作用边界是本项目的明确设计决策。**
