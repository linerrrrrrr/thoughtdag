# 设置页正文间距

在「界面与操作」中，「外观」标题应靠近第一项「语言」，「语言」与「界面主题」之间保持普通行距。「画布操作」开始一个新分区，前面留出更多空间。在窄窗口里，标签和控件换成上下排列时仍属于同一设置项。

仓库中的 `src/design-system/settings-spacing.json` 同时记录设计依据、项目取值和样式位置。在 `principles` 中可找到上游章节、原则及本项目的适配理由，在 `roles` 中可查每档间距的用途和数值。离线原文、固定版本和许可证的索引位于 `vendor/design-references/README.md`。

| 注册角色 | 测量的两个边界 | 设计依据 |
| --- | --- | --- |
| `hint` | 字段名或控件与自己的说明 | 让解释和所解释的内容处于同一视觉单元 |
| `heading` | 分区标题与第一项，或上下排列的标签与控件 | 标题贴近所属内容 |
| `row` | 同一组内相邻两个设置项的外缘 | 等距表明同级关系 |
| `section` | 前一组最后一项的下边缘与下一组标题或首项的上边缘 | 较大留白标出类别切换，有分隔线时两侧各分一半留白，线宽另计 |

像素数按界面缩放前的 CSS 尺寸登记。页面正文的多行文字继续使用字号角色的行高。控件的可点击高度、图标与文字的横向间隔，以及示意图自身的内边距由各组件管理。

## 修改和登记

1. 修改某档间距时，在 `roles` 中调整数值。说明、标题、行、分区依次递增。运行 `npm run spacing:sync`，从注册表更新设置页使用的 CSS 变量。
2. 添加设置项时，复用同类设置的分组、标题和字段样式。新设置页还需在 `pages` 登记所属设置分类，并在相应的 `bindings` 中列入该页。
3. 新的 CSS 选择器使用设置间距变量时，在 `bindings` 登记文件、选择器、属性、角色和适用页。分隔线两侧使用 `half` 分别登记。对照上游新增原则时，在来源清单保存快照并在 `principles` 关联具体章节。
4. 运行 `npm run spacing:check`。开发和生产构建会执行同一检查，来源快照缺失或受损、分类漏登、样式值偏离登记都会产生诊断。用 `npm run test:spacing-gate` 可在隔离副本里验证拦截与恢复。

## 检查实际页面

使用开发服务器运行 `npm run test:spacing-ui`。浏览器测试默认访问本机 5173 端口，其他地址可通过 `APP_URL` 指定。在桌面和窄屏布局下测量设置元素外缘的距离，扣除界面缩放和分隔线宽度，再与注册值比对。截图保存在 `local-tests/settings-spacing/`。
