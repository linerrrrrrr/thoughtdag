# 画布、导航与分区

## 浏览画布

- **按住鼠标中键或右键拖动**：平移画布；**按住空格再左键拖动**也可以；
- **滚轮或触控板双指滑动**：默认平移画布；节点正文内仍滚动阅读。可在 ⋯ 菜单关闭「滚轮平移画布」，恢复普通滚轮缩放；
- **Ctrl/⌘ + 滚轮或捏合**：始终以画布可视区域中心缩放，鼠标位于节点或输入框内也有效；Magic Mouse 用 Control 加点击打开右键菜单；
- **左键拖动空白处**：顶部工具栏的**框选对象 → 节点／线条**决定选择类型。节点模式需要完整包围每个节点；线条模式选择与选框相交的可见连线，不连带选中节点；
- **Ctrl / ⌘ / Shift + 点击**：追加或取消选择；按住这些键框选可追加选区，普通框选会替换原选区；
- **Ctrl / ⌘ + A**：按当前框选对象类型全选；画布获得焦点时，`Tab` / `Shift+Tab` 按顺序切换对象，输入框内保留文本和表单操作；
- **拖动节点**：调整位置。

右下角小地图和画布底部的缩放控件，也可以用来浏览大型图。

## 改变阅读距离

在「详细程度 → 随缩放」下，缩小画布时，节点会从完整卡片变为名称概览，再变为紧凑名称。节点位置与连线保持不变。详细程度只改变展示，不改变模型上下文，也不会触发摘要生成。

工具栏的「详细程度」可为未锁定节点统一选择「简略」「摘要」「完整」，不受缩放比例影响；查看全局时也可以保留完整内容。选中一个节点后可在同一面板设置，也可右键节点选择档位并锁定。「跟随全局（解除锁定）」恢复全局设置。节点锁定随项目保存并可撤销，全局偏好在当前浏览器中记忆。编辑或等待人工输入时保留输入区；点击已锁定节点的阅读入口可查看内容，不改变锁定设置。

进入地图层或图标层后，画布底部会出现两个入口：**导出思路地图**与**继续上次思路**。

## 从画布生成思路地图

点击**导出思路地图**，ThoughtDAG 会把当前节点、连线、材料与关键标记重新排成一张可分享的图片，而不是截取当前屏幕。

你可以：

- 手填公开标题、说明与署名，或让当前模型起草文字；
- 在**规范重排**与**手排**之间切换；
- 调整旋转、纸色、图面语言、字号、统计、时间墨色与日期；
- 检查信息流缩略图，再下载 PNG。

## 继续上次思路

鼠标停在**继续上次思路**上，地图会提示最近活跃的对话节点。点击后，画布会飞回该节点、恢复到可阅读缩放，并打开它的侧栏。

<img src="../../continue-last-thread-zh.gif" alt="从缩小的地图点击继续上次思路，飞回最近活跃节点并打开侧栏" width="100%" loading="lazy"/>

到达后可以直接追问，也可以选择**概括成便签**。生成的概括会作为未连线便签落在画布上：可以编辑或删除，但不会自动进入模型上下文。

如果你明确知道要找哪个节点，使用下面的搜索与键盘导航；如果只是隔了一段时间回来继续，使用**继续上次思路**。

## 找到节点

- 点击右上角的**搜索**按钮，或按 `Cmd+F` / `Ctrl+F`，查找问题、回答、便签、高亮、链接或材料名；
- 输入关键词后，不匹配的节点会淡出。使用 `↑` / `↓` 选择结果，按 `Enter` 飞到节点并打开侧栏中的命中位置；
- 点击一个节点后，它通向根节点的结构路径会高亮；
- 使用方向键沿结构连线移动，按 `Esc` 逐层退出。完整按键参见[键盘快捷键](/zh/reference/shortcuts)；
- 已有分区框时，右上角会出现**分区导航**按钮，用于在命名区域之间跳转。

## 整理布局

从[“更多操作”菜单](/zh/guides/interface-overview#更多操作-菜单)打开**排版设计**，点击面板内的**一键排版**即可整理当前选区，无选区时整理整张画布。它读取已保存的排版设置，保留尚未应用的设置草稿；也可在面板内调整方向、间距，先预览再明确应用。纵向排版时同一对话链同列，横向排版时同链同行，两种方向均遵守连线顺序。

自动排版按当前选区执行，未选节点保持原位。选中分区时会纳入当前框内内容，排版后适配边界，嵌套分区也会随内容调整。每次应用形成一个撤销步骤。

**选区属性**面板并列显示**对齐**和**创建分区**。对齐提供六种边缘或中心对齐、横向与纵向等间距分布，可参照所选对象或当前可视画布，每个所选节点独立参与。手动对齐与分布允许同链错开、上下游位置逆序及节点重叠；空间不足时仍按等间距分布，间距可以为负。点击后直接执行并可撤销，不改变连线与上下文；联动分区按既有成员规则携带内容。

**层级**与**对齐**并列，支持**上移一层、下移一层、置于顶层、置于底层**，节点和分区均可使用。多选时保留所选对象之间的叠放次序，每次操作可一步撤销或重做。取消选中或刷新后层级仍然保留，不改变对象的位置、尺寸、连线或上下文；调整分区层级只作用于实际选中的分区，不自动修改框内内容。

按住多选色块的任意位置（包括节点之间的空隙），可一起移动所选对象；已链接分区会携带内容，每个对象只移动一次。拖拽多选外框的右侧、底部或右下角手柄，可一起调整节点的宽、高或两个方向，节点位置保持不变，并遵守比例锁定与尺寸限制；右下角拖动时，锁定比例的节点按相对变化较大的方向等比调整。一次移动或缩放对应一次撤销，拖动中按 Esc 可恢复起点并保留选区。移动区或手柄获得焦点后也可用方向键按 1 px 调整，Shift + 方向键按 10 px 调整；显式拉伸后的高度在缩略视图中也会保留。

框选后矩形范围会保留，可在**节点／线条**之间切换，选择这次范围内完整包围的节点或相交的线条；即使当前类型没有命中对象，也能切回。缩放和平移时范围随画布移动，点击范围外或退出选区时清除。没有保留框选范围时，切到**线条**接续选择已选节点之间的连线，切回**节点**选择线条端点。工具栏下方的**批量编辑线条**沿用单条连线的用途选项、走线图示和标注样式，可统一修改这些字段；值不同时显示「多个值」，修改立即保存（包括清空标注），未改动字段保留各自原值，不再提供应用/取消按钮。每次选项修改和每次连续标注输入分别可一步撤销；特殊连线保留原用途。关闭面板保留已生效设置，Esc 只结束标注编辑，不回滚已保存修改。删除须确认，且只移除所选线条。

点击节点的书本按钮或右键菜单中的**查看详情**可独立阅读该节点，当前选区与对象格式面板保持可用。阅读对象固定，单击其他节点仅改变选区；再次点击**查看详情**才切换阅读对象。关闭详情不会清空选区。

## 使用分区框

分区框用于命名和视觉分组。当多条分支仍属于同一项目，但需要清晰分区时使用：点击或拖动左侧材料栏最下方的**分区框**按钮，把框放到画布上，再编辑标题和颜色。

也可点击对象格式面板中与对齐并列的**创建分区**按钮。新分区按当前所选节点确定边界，原节点的位置和上下文连线均保留。选区已包含分区框时，此按钮不可用。

分区框右上角的链条按钮控制移动关系：**已链接**时，拖动或对齐分区框会带动区域内对象；**未链接**时，只移动框本身。从所选对象创建的分区默认已链接，手动画出的分区默认未链接，便于先调整范围。

分区按空间范围组织对象：每个节点和子分区都必须完整位于框内。联动时框内节点随框移动，框外节点保持原位。节点移入移出或改变分区边界都会改变范围；重叠分区也可能覆盖同一个对象，移动、选择和复制内容时会去重。分区用于命名、视觉归类和导航，成员由当前范围决定，不自动汇入上下文。已有分区后，可以通过**分区导航**直接跳转。隐藏标注只会简化视图，不会删除内容。

点击分区的标题或边框选中框，按住 Ctrl / ⌘ / Shift 可以追加选择；框内空白处可以直接拖动框选节点。选中框本身不会自动选中内容。画布上的标题可双击改名，联动图标可快速切换移动方式，其余属性集中到工具栏下方的**分区设置**。

**分区设置**提供名称、颜色、尺寸与位置、纵横比锁定、移动方式和当前范围统计。标题允许清空；多选分区时可统一颜色、尺寸、比例锁定与移动方式，名称不批量修改。名称及几何输入遵守现有 Enter 完成、Esc 取消的编辑规则。

- **选择分区内容**：选择完整落在框内的节点，随后可使用摘要、归档与导出等内容操作；框本身不参与这些操作。
- **选择框及内容**：同时选择分区、内层分区和完整包含的节点；不会重复选择同一对象。
- **适配内容边界**：按执行时的内容范围调整边框并保留边距；空分区不执行，内容的位置和尺寸不变，已锁定的框保持比例。
- **复制框**：只复制所选框；**复制框及内容**：复制范围内对象与内部连线，不额外复制框外节点，也不携带跨出选区的连线。
- **删除框，保留内容**：仅删除分区本体；如果明确混选了节点，删除前会分别列出框和节点数量。

分区与节点混选时，面板分别显示数量，并用**节点／分区**切换当前属性编辑范围。尺寸设置只作用于当前类型，不会把外框和卡片一起改成相同尺寸；总选区包含多个对象时始终不提供坐标统一覆盖。拖动或对齐联动分区及其已选内容时，每个对象只移动一次。

## 对象格式面板

选中一个或多个节点后，工具栏下方会出现**对象格式**面板，用于调整节点的几何格式。面板可以收起，再次改变选区时自动展开；它与右侧节点详情可同时使用。通过节点上的书本按钮或右键菜单中的**查看详情**打开阅读。两个面板分别显示正在编辑和正在阅读的节点名称；窄窗口中上下排列并各自滚动。

**尺寸**可填写宽度、高度，单位为画布像素，不随显示缩放改变。锁定纵横比后，修改一边会按该节点原比例联动另一边，拖动缩放手柄也遵守锁定。多选尺寸不同会显示“多个值”；填写宽或高可批量调整，已锁定的节点分别保持各自比例。尺寸和锁定状态随画布保存。

**位置**只在单选时提供 X、Y 坐标，表示节点左上角的位置；多选不统一覆盖坐标，以免节点叠在一起。移动已链接的分区仍会带动其内容，修改分区尺寸则只改变范围。

尺寸和位置属于一个编辑区域：内部 `Tab` 切换不提前提交，`Enter` 或离开整个区域完成一次可撤销修改，`Esc` 放弃当前输入。**对齐**打开排列菜单，**创建分区**直接用所选节点建立范围框；对齐、分布点击后直接执行，并可撤销。内容操作区始终展开，摘要和归档等无需再展开查找。下表说明这些操作的结果。

| 操作 | 结果 |
|---|---|
| **合并摘要** | 保留原节点，建立综合节点 |
| **合并并删除** | 建立综合节点，再删除所选原节点 |
| **串联高光** | 当选区含高亮时，把所选高亮串成带来源的内容 |
| **归档** | 保留节点，但让它们退出上下文遍历 |
| **复制** | 复制选区及选区内部连线，不携带跨出选区的连线 |
| **对齐** | 对齐、分布当前选区，保留上下文顺序 |
| **创建分区** | 新建包住所选节点的命名区域，保留位置与连线 |
| **导出 .md** | 把所选节点导出为 Markdown |
| **删除全部** | 删除选区；执行前会确认 |

点击选区外或按 `Esc` 可以退出多选，点击目标的操作仍正常执行。对象格式面板、对齐菜单及框选对象切换属于选区编辑区域，操作它们不会清空选区；Ctrl/⌘/Shift 仍用于追加或取消选择。

其中，**合并摘要**与**串联高光**会建立新的[内容表示](/zh/guides/organize)，**归档**会改变[上下文遍历](/zh/guides/context-control#改变进入请求的内容)，**导出 .md**则属于[数据与分享](/zh/guides/data-sharing#导入与导出)。

## 画布与恢复

通过画布菜单新建、重命名、切换或删除画布。每张画布分别保存图、材料、布局和历史。互不共享上下文的工作使用不同画布；仍属于同一项目的方向使用分支或分区框。

使用 `Cmd+Z` / `Ctrl+Z` 和重做恢复近期操作。需要跨会话恢复时，启用[自动文件夹备份](/zh/guides/data-sharing#自动文件夹备份)。
