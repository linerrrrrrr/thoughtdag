# 对话节点与侧栏

## 开始并继续对话

在输入框中提出问题。问题与流式生成的回答会组成一个对话节点。从该节点继续提问，就会沿同一路径向下展开。

在首页、画布节点或右侧详情提问时，可以用回形针选取文件，也可以直接粘贴。附件排在问题文字上方。点击图片缩略图可查看全图，切换到原始尺寸可检查细节。点击附件可修改文件名、图片说明或随问题发送的文字。PDF 和 .docx 编辑的是提取出的文字副本。点击「保存」应用修改。点击弹窗外侧可暂存草稿，按 Esc 取消本次编辑。发送前可单独移除附件。支持图片、PDF、.docx、.ipynb 和文本文件。

从节点边缘拖出连线，落在画布空白处，创建空白子节点。在新节点中输入问题并明确发送。界面各区域的位置参见[认识界面](/zh/guides/interface-overview)。

## 认识对话节点

普通聊天使用统一的问答节点。起点标记由当前对话入边决定；多个子节点只是图中的不同路径。连线负责选择上下文。上下文变化后，可以在需要更新的节点上重新生成回答。针对材料选文提问时，引文直接显示在问题正文中。

节点卡片用于快速浏览，而不是承载全部控制：

- 顶部是节点状态与操作；
- 中间显示当前回答版本；
- 高亮区提供荧光笔，回答底部可重新生成、复制或编辑回答。
- 回答版本记录生成模型和生成时间；
- 琥珀色标记表示该回答早于上游变化，需要检查或重新生成；
- 缩小画布时，完整卡片会折叠为收获句，再折叠为图标标记。

**双击节点**进入完整侧栏；需要低频操作时，使用**右键节点**。

## 浮动侧栏的功能区

侧栏覆盖在画布右侧，不会挤压或移动节点。左边缘可以拖动调宽，双击边缘恢复默认宽度。

| 功能区 | 作用 |
|---|---|
| 顶部状态与操作 | 查看节点状态，并执行节点级快捷操作 |
| 问题 | 阅读或编辑当前问题；等待输入的节点也在这里填写问题 |
| 回答与版本 | 阅读完整回答、切换版本、查看生成模型 |
| 本轮信息 | 在回答下方查看 token 估算与附件数量 |
| 附件 | 加入[材料](/zh/guides/materials)，控制继承附件是否进入当前上下文 |
| 高亮 | 查看和删除高亮，选择仅供阅读、标注重点或仅传高亮；详见[高亮并串联](/zh/guides/organize#高亮并串联) |
| 回忆 | 查看检索到的历史条目与检索状态 |

详情页没有上下文节点列表、上下文链导航或来源排序分区。多路汇入时，在画布节点的**上下文 · N 路**入口检查来源和调整顺序；详见[控制上下文](/zh/guides/context-control)。标题栏的**更多**菜单仍可复制或导出上下文链。

## 从已有节点继续提问

从希望继续的节点拖线到空白处，在新节点填写并发送问题。可以从同一个节点创建多个子节点，分别讨论不同方向，原有问题和回答继续保留。

在**高亮**区开启荧光笔，在自己的问题、补充指令或助手回答中拖选文字，松开鼠标即保存。问答中出现相同文字时，可以分别标记。按 Esc 退出后即可正常选文和复制。

文档或对话中有高亮时，节点右侧会出现**概览标尺**。每个刻度对应一处高亮，位置反映它在全文中的先后。单击刻度即可跳到对应的高亮。把刻度拖到已有节点可以连线，拖到画布空白处可以新建一个相连的问题，输入后按发送即可。在 DOCX 工具栏点击荧光笔，然后划选原文。每次松手，节点右侧就出现对应刻度。悬停在笔上即可选色。再点一次笔或按 Esc 可退出。点击「保存」将这些高亮和正文修改一起写入节点文档。

## 编辑节点

- **双击问题**编辑问题；
- 点击回答末尾的**铅笔按钮**编辑回答；
- **双击节点**打开浮动侧栏。

修改上游内容后，依赖它的回答可能被标记为陈旧，而不是继续被当作当前结果。

## 重新生成与比较

**原地重新生成**会在同一节点增加一个回答版本。若要让不同答案在图上并排保留，则建立新的兄弟节点。详见[版本、陈旧与重放](/zh/guides/versions-replay)。

## 节点右键菜单

右键菜单集中放置低频操作；每一项的用途已经在[认识界面：节点](/zh/guides/interface-overview#_3-节点)中逐项说明。这里需要记住两点：菜单会随节点类型和状态变化；选中文字后右键时，会保留浏览器原生文字菜单。
