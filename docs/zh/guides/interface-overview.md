## 1. 顶部工具栏

左上角工具栏可以切换画布和默认回答模型。模型菜单还提供通往回答模型设置的快捷入口。右上角工具栏提供以下功能。

- 点击**设置**后，大窗口居中覆盖画布，四周留有边距。桌面可在左侧的**画布**和[**模型与工具**](/zh/guides/models-tools#连接并选择模型)中选择分类，窄屏则使用窗口顶部的分类选择器。
- [**分区导航**](/zh/guides/canvas-projects#使用分区框)：仅在画布包含分区框时出现；
- [**搜索节点**](/zh/guides/canvas-projects#找到节点)、[**本地自动备份**](/zh/guides/data-sharing#自动文件夹备份)；
- [**排版**](/zh/guides/canvas-projects#整理布局)可以整理当前画布或选区。**设置 → 连线走向**调整本机各画布的默认走线。
- [**更多操作**](#更多操作-菜单)、[撤销与重做](/zh/guides/data-sharing#恢复修改)。

在**设置 → 界面与操作**中可选择语言、界面主题和画布背景。选择网格会启用节点吸附。「显示批注」控制分区框和未连线材料的可见性。在**节点显示**中可调整全局详细程度、画布字号和固定输入区。

### “更多操作”菜单

右上角的 **⋯** 集中放置低频的整张画布操作：

| 菜单项 | 作用 |
|---|---|
| [**全部高光**](/zh/guides/organize#高亮并串联) | 汇总整张画布的高光，可定位原节点、勾选串联或导出 Markdown；仅在已有高光时出现。 |
| [**全部材料**](/zh/guides/materials#其他材料操作) | 集中查看画布中的文件、图片、链接等材料，并返回它们在画布中的位置；仅在已有材料时出现。 |
| [**凝练**](/zh/guides/organize#凝练一条路径) | 检查适合降低颗粒度的连续对话，并在原图右侧生成凝练副本；原图保持不变。 |
| [**诊断画布**](/zh/features#整理与重放) | 检查残差边、影子引用和过长链路等结构问题，给出报告但不自动修改。 |
| [**分享画布**](/zh/guides/data-sharing#分享画布文件) | 导出完整画布文件或思路地图图片；画布文件可附只读标记。 |
| [**导出备份 (.json)**](/zh/guides/data-sharing#导入与导出) | 把当前项目的节点、连线和内容导出为本地 JSON，用于备份、迁移或恢复。 |
| [**导出事件日志 (.csv)**](/zh/guides/data-sharing#导入与导出) | 导出带时间戳的提问、生成、高光和归档等操作记录；有事件记录时才出现。 |
| [**记忆**](/zh/guides/models-tools#管理环境记忆) | 查看、编辑、导入或导出跨画布的环境记忆。记忆开启时，已接纳的条目会进入普通生成的系统层。 |
| [**如何使用**](/zh/) | 打开应用内置的十步交互教程和快捷键提示。 |

菜单项随当前画布内容变化。


## 2. 画布

画布是主要工作区。按住鼠标中键或右键拖动可以平移，按住空格再左键拖动也可以。滚轮和双指滑动默认平移，捏合或 ⌘/Ctrl 加滚动用于缩放。要用普通滚轮缩放，在**设置 → 界面与操作**中关闭「滚轮平移画布」。左键拖动空白处用于框选，双击空白处新建问题，拖动节点调整位置。选中一个或多个节点后，工具栏下方会出现[对象格式面板](/zh/guides/canvas-projects#对象格式面板)，并列提供**对齐**菜单和直接**创建分区**按钮。画布底部还有缩放控件，右下角小地图也可以平移和缩放。完整操作见[画布、导航与分区](/zh/guides/canvas-projects)。

## 3. 节点

画布上有三类主要节点：

| 类型 | 保存什么 | 如何建立与打开 |
| --- | --- | --- |
| **问答节点** | 一次提问及其回答版本 | 提问或沿现有回答继续；双击节点打开[浮动侧栏](/zh/guides/conversations#浮动侧栏的功能区) |
| **便签节点** | 可直接编辑的文字或 Markdown | 新建便签，或把普通文字粘贴到画布 |
| **材料节点** | PDF、图片、Word `.docx`、HTML、Markdown、纯文本与常见代码文件，以及网页快照 | 拖入或粘贴文件；把单独的网页 URL 粘贴到画布会保存抓取时间与当时的页面内容；双击进入[材料阅读器](/zh/guides/materials#认识阅读器) |

问答节点保存一轮问题和回答。**双击问题**可以修改问题；回答使用末尾的**铅笔按钮**编辑。**右键节点**打开节点操作菜单，详见[对话节点与侧栏](/zh/guides/conversations#节点右键菜单)。

### 问答节点的语义图标

较长的回答完成后，ThoughtDAG 会在后台为当前问答生成一句地图摘要，并判断这一轮在思考过程中起到的作用。缩小画布时，节点会显示相应图标：

| 图标 | 含义 |
| --- | --- |
| **✦** | 洞见：得到或确认了一项认识 |
| **✕** | 排除：否定了一个假设或选项 |
| **⚖** | 决策：在多个选项中作出选择 |
| **↩** | 转向：重新界定问题或改变方向 |
| **?** | 未解：留下一个尚未回答的问题 |

这些图标**不是新的节点类型**，只是帮助浏览思路的语义标记；它们不会改变节点内容，也不会自动改变模型上下文。较短或尚未分类的问答节点在最远视图中显示为普通圆点。

## 4. 连线

- **紫色实线**：主要对话路径，传递完整上游上下文；
- **紫色虚线**：摘要引用，只把指定节点的问答和上游问题线索带入；

选中可转换的连线后，会显示预计 token 和转换按钮；也可以删除该连线。详细说明见[控制上下文](/zh/guides/context-control)。

## 5. 浮动侧栏

[浮动侧栏](/zh/guides/conversations#浮动侧栏的功能区)显示完整问题与回答、当前版本、高亮、token 估算、附件和回忆。它覆盖在画布上方，不会改变节点的实际位置。详情页不设置上下文节点列表或来源排序分区。

## 6. 在画布上继续提问

从当前节点拖出连接到画布空白处，创建子节点，再在新节点输入并发送下一问。多路来源汇入时，通过节点上的**上下文 · N 路**打开独立来源卡片，检查来源和调整汇入顺序；详见[控制上下文](/zh/guides/context-control#检查下一次请求)。
