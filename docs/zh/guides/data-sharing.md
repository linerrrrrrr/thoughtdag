# 数据、备份与分享

## 先开启自动文件夹备份

ThoughtDAG 默认把画布保存在本机应用数据中。为了获得一份**看得见、可以复制、也可以重新导入的真实文件**，建议在桌面版首次使用时就开启自动文件夹备份。

![从画布右上角打开本地自动备份，并立即写入当前画布](../../auto-backup-zh.gif)

### 开启方法

1. 点击画布右上角的**文件夹备份**按钮，打开**本地自动备份**；
2. 选择一个你能够长期保留的文件夹；
3. 授权成功后，当前画布已有内容时会立即写入一次；
4. 此后节点或连线每次发生变化，都会重新开始约一分钟的等待；停止改动后，当前画布会更新为一个以画布名称命名的 `.thoughtdag.json` 文件。

选择网盘同步目录时，文件会沿用该目录本身的同步方式；ThoughtDAG 不需要为此建立账号或上传到自己的服务器。

### 它具体会保存什么

每张画布对应一个完整备份文件，包含节点、连线、附件内容和事件记录。文件名由画布名称和画布 ID 组成，避免同名画布相互覆盖；非法文件名字符会被替换。

| 情况 | 自动备份的行为 |
|---|---|
| 开启备份时，当前画布已有内容 | 立即写入当前画布 |
| 连续编辑节点或连线 | 等最后一次改动约一分钟后写入，避免频繁保存 |
| 切换到另一张画布并修改 | 为那张画布写入自己的文件 |

自动备份写入的是**当前活动画布**，不是每分钟扫描并重写所有画布。需要立即确认时，重新打开备份控制中心，点击**立即备份当前画布**；这里也可以查看文件夹、上次写入时间、更换目录或停止备份。

每次打开桌面 App，ThoughtDAG 都会恢复上次记录的备份文件夹并尝试继续监听画布变化。若操作系统仍保留文件夹权限，自动备份会直接继续；若系统要求重新确认，点击**重新授权，继续备份**即可恢复。

### 从备份恢复

打开画布菜单，选择**导入备份**，再选择 `.thoughtdag.json` 文件。恢复的是完整画布，不只是可阅读的导出文本。

桌面版提供最完整的体验；浏览器版本只有在环境允许访问文件夹时才会显示这一入口。

## 手动导入与导出

- 在画布右上角选择 **更多 → 导出画布 (.html)**。用浏览器打开文件，即可离线浏览画布、点开节点并阅读文档。
- 使用**导出备份**随时保存一份完整图，并在之后恢复；
- 把一条上下文链或所选节点导出为 Markdown；
- 按需导出高亮、记忆或事件元数据；
- 导入兼容的 ThoughtDAG 备份或受支持的对话导出。

导入内容中的编辑与重新生成版本，可以成为可见分支，而不是被压平成一段聊天记录。

## 分享画布文件

通过**分享画布**导出完整的 `.json` 文件或思路地图图片。勾选只读标记后，对方导入 JSON 时会看到提示；导入后仍可创建可编辑副本。

在画布菜单选择**导出画布 (.html)**。浏览器离线打开后，会显示导出时的画布位置、缩放、配色、节点详略，以及当时打开的详情或阅读窗口。文件包含当前视野以外的节点、已保存的版本、文档分页和批注。浏览时可以平移或缩放快照，展开节点阅读正文。

### 只读画布摘除清单

| 范围 | 保留 | 从导出副本摘除 |
| --- | --- | --- |
| 画布导航 | 当前画布名称、分区导航、小地图、平移、缩放、适配全图 | 切换项目、模型选择、应用内搜索、问画布、设置、更多菜单、撤销与重做 |
| 画布结构 | 节点、分区、连线、标签、端口及原位置 | 新建工具栏、排版、选区属性、连线编辑、尺寸手柄与交互锁 |
| 问答和节点详情 | 已保存的问答、来源、摘要、版本、高亮、详情开关和标尺定位 | 输入框、改写、删除、发送、重新生成、执行与终端入口 |
| 材料阅读 | 附件名与正文、页面、图片缩放、已有批注、阅读窗停靠与展开 | 文件导入与写回、编辑工具栏、添加或删除批注、识别、生成导读及追问 |

承载内容的按钮会保留其中的已保存文字或图像，例如画布名称、来源材料名和附件缩略图。只有具备离线阅读动作的按钮才作为控件保留。

## 恢复近期修改

使用 `Cmd+Z` / `Ctrl+Z` 和重做恢复近期操作。自动文件夹备份用于恢复文件；大规模整理或升级版本前，可以再手动导出一份备份。

**本地优先**不等于数据永远不会离开设备。远程模型或工具请求、导出和备份文件夹，都可能在你明确操作时传输数据。
