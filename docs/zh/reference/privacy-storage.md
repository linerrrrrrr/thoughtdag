# 隐私与存储

## 哪些内容留在本机

画布、模型凭证、导入文档和本地 session 镜像都保存在你的机器上。默认画布状态使用浏览器 IndexedDB；可选文件夹备份写入 `.thoughtdag.json` 文件。

本机部署可设置绝对路径 `THOUGHTDAG_HOME` 并启用 `THOUGHTDAG_DISK_STORAGE=1`，将画布、附件和设置写入该目录的 `browser-storage`，工作区写入 `workspaces`。首次打开每个浏览器地址时，程序会复制旧数据、读回校验，再切换到新位置；旧浏览器数据会保留。不同地址的数据分别存放，不自动合并。

浏览器仍保留连接数据目录的定位信息和文件夹授权。清除浏览器数据后，再打开原地址可选择重新连接已有本地数据；如果本地存储服务不可用，画布会停止打开并提示重试。文件夹备份仍是独立功能。

## 如何按编号编辑画布文件

本地文件节点在导入时复制文件内容。桌面应用或连接本机文件服务的画布会在画布工作区的 `.thoughtdag/documents/` 中维护普通文件。同名文件按节点和附件分开保存。对原生 Agent 说“修改 #12 的结论”，它会拿到当前画布对应文件的路径；文件保存后，原节点和阅读器会载入新版本。支持段落预览的工具还能在 DOCX 保存前显示正在替换的文字。

导入来源由你自行管理。原生 Agent 处理其他目录时沿用本机工作目录和权限设置；你可以在画布中明确选择另一种审批模式。纯浏览器部署把节点文档保存在浏览器中。

## 哪些内容可能离开设备

只有需要传输的功能会把内容送出设备：

- 向远程 endpoint 发起模型请求；
- 使用搜索或外部工具；
- 创建并发送分享 URL；
- 把备份文件夹交给第三方同步服务；
- 把导出文件发送给他人。

普通阅读时 PDF 留在本机。被选入远程模型请求的提取文字或材料可能会发送给对应 endpoint。

## 凭证

界面中配置的 key 保存在本机应用数据中，不进入普通画布备份。启用本地磁盘存储后，设置文件可能包含明文密钥，应限制数据目录的操作系统访问权限。你仍需检查所连接模型或工具服务的隐私政策。

## Why 层的本地索引

CLI 与 MCP 将可重建的索引和缓存保存在 `THOUGHTDAG_HOME`；未设置时使用 `~/.thoughtdag`。这些数据与原始 Agent 会话日志分开，可能包含历史问题、回答、文件路径和材料片段，并非只有文件名。

```bash
thoughtdag purge --cache  # 只删除可重建缓存
thoughtdag purge          # 删除全部派生数据，不删除原始会话
```

后续索引或查询可以重新读取仍存在的来源日志，因此删除索引不等于删除来源历史。

## Harness 插件

嵌入画布使用 Harness 网页来源下的浏览器存储；模型配置、凭证和会话日志由 Harness 管理。插件访问的是运行 Harness 的机器上的受支持日志，不一定是浏览器所在设备。

Agent 调用查询工具后，命中的历史内容可能进入其下一次模型请求；使用远程模型时，这些内容可能发送给相应服务。通过 **DeepSeek Harness · Agent** 发出的新轮次会写入 Harness 会话日志，编辑画布不会删除那份日志。

## 在线 Demo

在线 Demo 的画布保存在浏览器本地，支持时使用浏览器直连模型。它不包含完整的桌面本地能力。
