# 隐私与存储

## 哪些内容留在本机

从源码项目运行时，画布清单、节点、连线、附件记录和应用设置默认写入项目内的 SQLite 数据库 `local-data/data/thoughtdag.sqlite`。同一项目的本机浏览器入口和 Electron 共用这份数据库。稳定版和推进版各自在自己的项目目录中保存数据。`local-data/` 已排除在 Git 版本管理之外。纯静态网页使用浏览器 IndexedDB，可选文件夹备份生成 `.thoughtdag.json` 文件。

本机部署可以通过 `THOUGHTDAG_HOME` 和 `THOUGHTDAG_DISK_STORAGE=1` 显式指定数据根目录。已有的自定义目录继续兼容原有文件存储。使用同一数据目录的本机地址和端口共享画布、附件与设置。

将已有本机项目迁入源码目录时，先关闭使用旧目录的实例，再运行 `node scripts/migrate-project-data.mjs "<旧数据根目录>" "<项目目录>/local-data/data"`。每份旧库分别迁入对应项目。画布的外部文件和可编辑文档位于数据库旁的 `workspaces/` 中，完整备份应包含整个 `local-data/data/` 目录。

首次升级会合并同一数据目录下的旧清单。不同 ID 的同名画布分别保留，空的默认占位画布经核对后可以略过。原清单所在的其他存储目录归入 `browser-storage/legacy-backup/`。以前仅存于浏览器的内容在首次接入时复制并读回校验，原始浏览器记录保留。清除浏览器数据后再次打开会自动连接该项目。本地服务不可用时，页面提供重试。

每张本机画布都有一个供外部工具使用的文件夹。新建或导入画布时，应用会在数据目录下创建 `workspaces/<项目存储 ID>/<画布 ID>/external/`，升级时也会为旧画布补建。迁移前已存有外部文件的画布会沿用原目录。从画布运行 Codex 时，相对路径以该画布的目录为起点。画布改名或归档后路径保持稳定，删除画布时也会保留外部文件。目录里的文件由你管理，画布的节点和附件仍通过原有入口编辑。

## 如何按编号编辑画布文件

本地文件节点在导入时复制文件内容。桌面应用或连接本机文件服务的画布会在画布工作区的 `.thoughtdag/documents/` 中维护普通文件。同名文件按节点和附件分开保存。对原生 Agent 说“修改 #12 的结论”，它会拿到当前画布对应文件的路径；文件保存后，原节点和阅读器会载入新版本。支持段落预览的工具还能在 DOCX 保存前显示正在替换的文字。

导入来源由你自行管理。原生 Agent 处理其他目录时沿用本机工作目录和权限设置；你可以在画布中明确选择另一种审批模式。纯浏览器部署把节点文档保存在浏览器中。

## 哪些内容可能离开设备

只有需要传输的功能会把内容送出设备：

- 向远程 endpoint 发起模型请求；
- 使用搜索或外部工具；
- 把备份文件夹交给第三方同步服务；
- 把导出文件发送给他人。

普通阅读时 PDF 留在本机。被选入远程模型请求的提取文字或材料可能会发送给对应 endpoint。

## 凭证

界面中配置的 key 保存在本机应用数据中，不进入普通画布备份。启用本地磁盘存储后，设置文件可能包含明文密钥，应限制数据目录的操作系统访问权限。你仍需检查所连接模型或工具服务的隐私政策。

## Why 层的本地索引

CLI 与 MCP 将可重建的索引和缓存保存在 `THOUGHTDAG_HOME`；未设置时使用 `~/.thoughtdag`。这些数据与原始 Agent 会话日志分开，可能包含历史问题、回答、文件路径和材料片段，并非只有文件名。

```bash
thoughtdag purge --cache  # 只删除可重建缓存
thoughtdag purge          # 删除全部派生数据，不删除原始会话
```

后续索引或查询可以重新读取仍存在的来源日志，因此删除索引不等于删除来源历史。

## Harness 插件

嵌入画布使用 Harness 网页来源下的浏览器存储；模型配置、凭证和会话日志由 Harness 管理。插件访问的是运行 Harness 的机器上的受支持日志，不一定是浏览器所在设备。

Agent 调用查询工具后，命中的历史内容可能进入其下一次模型请求；使用远程模型时，这些内容可能发送给相应服务。通过 **DeepSeek Harness · Agent** 发出的新轮次会写入 Harness 会话日志，编辑画布不会删除那份日志。

## 在线 Demo

在线 Demo 的画布保存在浏览器本地，支持时使用浏览器直连模型。它不包含完整的桌面本地能力。
